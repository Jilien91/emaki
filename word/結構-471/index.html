結構

けっこう

all right, no thank you

Mnemonic

The thread tied off and the frame already built, so nothing more is going into it. Your hand goes flat over the glass before the bottle is halfway across: けっこう.

Worth knowing

Same word as 結構 "quite". This one turns things down, politely and firmly, and the tone is what tells you which you are getting.

Built from

結
tie, bind
糸 thread + 吉 good fortune
構
construct, frame
木 a tree on the left. Timber put together into a frame, so the way a thing is built up.
